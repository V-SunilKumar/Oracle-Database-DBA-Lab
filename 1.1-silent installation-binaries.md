# Method 2 — Silent installation using a response file
Supply configuration values in a .rsp file and run runInstaller -silent.
- No graphical interface required.
- Repeatable and suitable for automation.
- Excellent DBA practice for building multiple lab.

### Note : Oracle's official documentation states that Oracle Database 19c 19.32 or later is recommended on Oracle Linux 9. It describes downloading the 19.3 Database Home image and applying the appropriate Release Update during installation.

## Step 3 - Create the Oracle groups
We'll create the Oracle Home as root, then give ownership to the Oracle software owner, svanapal.
First, verify whether the required Oracle groups already exist. Run this command as your current user:
```
echo "===== ORACLE USER ====="
getent passwd svanapal

echo
echo "===== ORACLE GROUPS ====="
getent group oinstall
getent group dba
getent group oper

echo
echo "===== U01 FILESYSTEM ====="
df -hT /u01
```
We found two things to address before installing Oracle 19c:
- The groups oinstall and dba do not exist.
- /u01 has a 20 GB filesystem with approximately 20 GB free. That may be tight once the database software and patches are installed, so we'll monitor space carefully.

```
Create the Oracle groups. Run the following commands using sudo:
sudo groupadd oinstall
sudo groupadd dba

sudo usermod -g oinstall -aG dba svanapal

Verify the groups. Run these commands as svanapal:
echo "===== USER GROUP MEMBERSHIP ====="
id svanapal

echo
echo "===== OINSTALL GROUP ====="
getent group oinstall

echo
echo "===== DBA GROUP ====="
getent group dba

=============================================================================================
OUTPUT:
===== USER GROUP MEMBERSHIP =====

===== OINSTALL GROUP =====

```

## Step 4 — Create the Oracle Home directory

Create the Oracle directories
We will create the Oracle Base, Database Home, and central inventory directories. The inventory will be outside the Database Home so it can track Oracle installations independently.
Run the following commands:
```
sudo mkdir -p /u01/app/oracle/product/19.0.0/dbhome_1
sudo mkdir -p /u01/app/oraInventory

sudo chown -R svanapal:oinstall /u01/app/oracle
sudo chown -R svanapal:oinstall /u01/app/oraInventory

sudo chmod -R 775 /u01/app/oracle
sudo chmod -R 775 /u01/app/oraInventory

Verify the Results:
echo "===== ORACLE BASE ====="
ls -ld /u01/app/oracle

echo
echo "===== DATABASE HOME ====="
ls -ld /u01/app/oracle/product/19.0.0/dbhome_1

echo
echo "===== CENTRAL INVENTORY ====="
ls -ld /u01/app/oraInventory

echo
echo "===== AVAILABLE SPACE ====="
df -h /u01
```
